# Toán 12 — bản phẳng, không dùng thư mục

Tất cả file nằm cùng một cấp để upload GitHub dễ hơn.

## Các file chính
- `index.html` — trang chủ
- `gui-bai.html` — gửi bài / hỏi bài
- `giai-dap.html` — danh mục bài tập & giải đáp
- `chuong-1.html` — bộ bài Toán 12 Chương I
- `luyen-tap.html` — luyện tập tự chấm
- `style.css` — giao diện chung
- `common.js`, `submit.js`, `practice.js` — JavaScript
- `hero-learning.png` — ảnh đồ họa trang chủ
- `favicon.svg` — biểu tượng tab trình duyệt
- `404.html` — trang lỗi
- `vercel.json` — cấu hình Vercel

## Upload GitHub
Chọn toàn bộ file trong thư mục này và kéo thẳng vào GitHub.
Không cần giữ folder con nào.

## Vercel
Import repo GitHub và chọn:
- Framework Preset: Other
- Root Directory: ./
- Build Command: để trống
- Output Directory: để trống
